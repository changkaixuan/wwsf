字符终端说明 WWS任务调度系统是需要字符命令执行完成，熟练掌握和使用每一个命令是正确使用调度系统的前提。成功启动字符终端后就可以执行相关的调度命令。

字符终端命令一览 批量操作命令: batch
定时任务命令: c-cj-list cj-install cj-start cj-stop cj-list
数据源命令: c-ds-info c-ds-list ds-create ds-destroy ds-info ds-install ds-list
节点操作命令: c-plu-pools c-plu-pool-resize nodes plu-pools plu-pool-resize spof sr-info sr-mqueue sr-release
加解密命令: decrypt-key decrypt-text encrypt-key encrypt-text
job操作命令: j-disable j-driver j-info j-ins j-pause j-query j-renovate j-rerun j-rerunfailed j-rerununpassed j-update t-info t-update t-updatebytid
sql操作命令: exe-sqlfile

批量操作命令

命令 描述 语法
batch 展示批量任务列表 wws:batch [options] [batch]

batch 展示批量任务列表

参数/选项 默认值 是否必填 描述
batch 无 否 查询的批次号
-s 30 否 每页显示的记录数目
-p 1 否 当前显示的第几页
-i 无 否 打印的间隔时间(s)，如设置，需大于0
-t 当设置-i，未设置-t时，-t默认不限次数打印 否 job运行状态打印次数,如果该参数count大于0,则打印count次，如果小于0,则不限次数打印
--help 无 否 显示命令的帮助信息
