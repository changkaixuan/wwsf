1. 概述

WWSF是一个轻量级分布式任务调度平台，可提供多产品同平台调度，以插件开发的方式提供不同作业类型的扩展。

简短的介绍平台特性：

  • 灵活的参数传递，提供任务间参数传递，支持占位符变量替换，支持表达式计算。可实现大部分场景下作业接口，从而减少应用内部使用额外的介质进行数据交互。

  • 丰富简易的流程配置，提供网状模型和网维模型的作业执行引擎，贴近企业作业调度需求，以最小的配置量，完成最多的任务执行。

  • 多种操作控制台，调度提供了命令行控制台（shell console）和网页控制台（web console），提供了40多个命令和20多项功能菜单，集辅助开发，维护，监控预警与一体的综合平台。

  • 提供平台级数据源和计划任务服务，为应用提供一些常用的服务，实现集中式管理，分布式执行，为用户任务执行提供基础资源，使用户在任务流程设计上更关注业务逻辑规则。

  • 十万级作业量支持，强大的调度引擎，灵活的并发参数设置，为多产品大量作业同平台调度提供可能。

  • 开放性，Restful规范实现开放接口，共设计5大类30多个公共接口，方便二次开发和第三方集成。

2. 快速开始

本章节可以帮助用户在5到15分钟内，安装和运行WWSF，并提供调度主节点和web-console应用，使用web-console应用快速的启动一个示例任务。

2.1. 安装要求

  • 要求安装 8或更高版本Java SE环境。

  • 提供一个MySql数据库实例或者Oracle数据库实例。

  • 提供一个Zookeeper实例,用于插件服务注册和分布式协调。

  • 下载WWSF的二进制压缩包，wwsf 和 wwsf-console（两个zip包）。

  • 在你的操作系统上（以linux为例）创建一个用户wws或者与产品共用用户也可，并创建一个目录，如：/home/wwsf 或者 /home/rdmn/wwsf。

  • 给予2Core处理器，5G的磁盘空间,3G以上空闲内存，视任务量级可自主扩展系统资源。

  • 开放8585·10999·44444·8101端口，保持端口不要被其他进程占用。

点击菜单【参数设置】，打开参数设置界面

  • 预警参数

    选中预警参数前复选框，将启用参数，反之不启用。如: 选中任务执行超过多少秒、需人工干预和任务失败重试次数，在任务执行过程中，遇到选中的三种情况，将发送消息提醒。消息可通过点击界面右上角 查看。

    可以根据产品查询清理策略。

    • 清理Job执行历史

      全局参数，选中清理Job执行历史前复选框，调用存储过程清理时会清理Job执行的历史记录，保留当前设定的数量。

    • Job实例清理策略

      用于删除任务实例信息

      • 新增

        点击“新增”按钮，会打开编辑清理策略界面。

      • 修改

        鼠标双击Job实例清理策略列表的记录，打开编辑清理策略界面。

      • 编辑清理策略界面

        清理策略属性说明

        • 策略编号

          所有策略编号不能重复；策略编号只能为数字、字母或者下划线组成。

        • 产品

          通过菜单【系统管理/产品管理】维护产品；通过菜单【系统管理/用户管理】维护用户产品关系。

        • 任务名称

          点击任务名称，变成紫色后视为选中该任务；再次点击，变成灰色后视为取消选中该任务。

        • 保留时间

          最小值为0， 不能为负数；任务实例的初始化时间超过保留时间，任务实例数据将被删除；计划任务日志的开始时间超过保留时间，计划任务日志数据将被删除。

        • 清理正在执行

          勾选清理正在执行，清理Job实例时正在运行的任务会一并清理；反之不会清理。

      • 删除

        点击Job实例清理策略列表每一行中“删除”按钮，会删除该Job实例清理策略。

    • Cron日志清理策略

      用于删除计划任务日志信息

      • 新增

        点击“新增”按钮，会打开编辑清理策略界面。参见编辑清理策略界面

      • 修改

        鼠标双击Cron日志清理策略列表的记录，打开编辑清理策略界面。参见编辑清理策略界面

      • 删除

        点击Cron日志清理策略列表每一行中“删除”按钮，会删除该Cron日志清理策略。

  • 执行清理策略

    • 新增计划任务方式执行清理策略

      • 新增计划任务，插件和程序名称都选ds-procedure，计划任务参数（{ds.name:在线的数据源名称, parameters:'产品号','登录名',null或'清理策略编号', parameters.model:2, procedure:P_WWS_CLEAR}）

    • 新建任务模板方式执行清理策略

      • 新增任务项，插件和程序名称都选ds-procedure，任务项参数（{ds.name:在线的数据源名称, parameters:'产品号','登录名',null或'清理策略编号', parameters.model:2, procedure:P_WWS_CLEAR}）
