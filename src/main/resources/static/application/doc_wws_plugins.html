插件使用说明 插件主要是为了对各种类型作业的适配支持，wwsf将提供一些通用作业的适配插件，如对shell、bat作业；数据库SQL、存储过程作业；文件处理作业等。插件同时亦是一些经过封装的拥有某项基本功能的原子组件，如批量切换、信息采集等组件。插件为调度平台的最小任务执行单元。如果平台提供的标准插件无法满足要求时，用户还可以自定义插件来完美适配个性作业。
一个插件会定义一组输入参数，其中包含必填项和非必填项，必填项参数在插件执行时必须传值，是插件执行的必要参数。其表现形式类似于编程语言中的函数。
插件一般在计划任务和流程任务中使用。

变量的使用

我们在实际配置当中，插件的参数值在大部分情况下是变化的，如果是一成不变的常量那作业配置缺乏灵活性，可复用性降低。那么如何在参数赋值时使用变量，让任务在执行时得到预期的参数赋值呢，这将是本小节主要讲解的内容。
任何一个参数赋值时，都可以使用${xxx}占位符的方式来引用变量，当然这个变量必须是Job中已配置的常量或者是用户在实例化Job时传入的参数，亦或是Jvm环境变量或调度提供的内置变量。因此在我们配置作业时，我们用到的变量一般有三种：用户JOB中配置的常量，用户实例化Job时传入的变量，以及调度提供的内置变量。
如下传平台12.3.gz.9格式文件名：${logic.name}.gz.${accutDate}0
针对${xxx}占位符替换优先级：Task维度 > Task传入参数 > Job传入参数 > Jvm内置变量。
