The Platform for Job Sheduling And Also Provides Service Shared and Integration

网维分布式调度系统提供作业调度的基础平台，基于PaaS理念，提供集开发、部署、测试、监控于一体的渐进式基础开发框架，平台开发所有组件都符合SOA标准，并实现即插即用功能.平台基于RESTful规范开发了丰富开放式接口.

配置简单

提供SHELL控制台和WEB控制台，用户能便捷的配置包括假日编排、维度、任务流、计划任务、数据源、调度节点、产品等信息。Job支持网状驱动模型和网维驱动模型两种， 网维模型旨在极少配置的情况下，运行更多任务（Less configuration and run more）。

运行稳定，高效

经过2年的发展，迭代版本20多个，目前在近20个产品的生产环境使用，日调度任务数量合计20万，系统稳定运行，在非投产变更期间，无需人工干预运行。 在测试环境测试2万任务量运行（每个任务执行一个echo语句），在单个代理节点，20并行线程的情况下，用时不到5分钟跑完。平台已达到10万任务级以上调度能力。 在AIAP生产环境4代理节点架构，日调度任务数量11万。

高可用，高容错

部署架构可自由灵活选择，具有横向扩展能力。最小高可用集群Master-HA（两节点），Mlt-Slave（两节点）架构，具有故障转移恢复能力，Master宕机时，Master备机节点会接管任务驱动，保证作业流继续运行； Slave宕机时，其上的作业将会被接管分配到其他Slave上继续执行，作业支持错误重跑。
